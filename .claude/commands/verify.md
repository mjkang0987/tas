현재 변경을 검증한다. `CLAUDE.md` 세부 규약: 항상 빌드/타입체크, 런타임 변경은 실제 구동, 문서·설정만이면 빌드만.

## 1. 변경 범위 판단

`git status --short` 와 `git diff --stat` 으로 무엇이 바뀌었는지 먼저 본다.

- 문서·설정(`*.md`, `.claude/**`)만 바뀌었으면 → 3번만 하고 끝낸다.
- 코드 변경이 섞여 있으면 → 아래 전부.

## 2. 테스트

```sh
cd client && pnpm test
```

- 이번에 만졌거나 새로 만든 **순수 함수**가 있으면 테스트도 같이 추가한다.
- 추가한 테스트가 처음부터 통과하면 **소스를 일부러 망가뜨려 실패하는지 확인**한다. 실패하지 않는 테스트는 회귀를 못 잡는다.
- DB·React 렌더링이 필요한 코드는 아직 테스트 환경이 없다. 그 경우 4번으로 대신하고, 대신했다는 사실을 보고에 적는다.

## 3. 빌드 + 타입체크

```sh
cd client && pnpm build   # prisma generate + next build
cd client && pnpm lint    # advisory — 실패해도 중단하지 않되 내용은 보고한다
```

## 4. 실제 구동 (런타임 변경일 때만)

`/run` 으로 앱을 띄워 **대상 흐름을 직접 구동**한다. 테스트 통과로 갈음하지 않는다.

## 5. 보고

통과·실패를 있는 그대로 적는다. 실패면 출력을 그대로 붙인다. 건너뛴 단계가 있으면 무엇을 왜 건너뛰었는지 밝힌다. "아마 될 것"으로 넘기지 않는다.
